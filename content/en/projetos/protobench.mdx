ProtoBench is basically a Tinkercad I built to understand and design circuits better, both for studying and for direct integration with AI. You build the circuit on a breadboard, perfboard, stripboard or Arduino/ESP32, wire up the parts and see how it behaves before soldering anything. It runs right in the browser: [jovidasilva.github.io/ProtoBench](https://jovidasilva.github.io/ProtoBench/).

## How it works

The simulation actually solves the circuit. It becomes a system of equations through modified nodal analysis, solved with the Newton-Raphson method, which is what makes it possible to simulate parts like diodes, transistors, regulators, relays and PWM. There's also an Arduino code interpreter that reads, checks and runs the sketch.

The app also reviews the layout: it finds the electrical connections, solder points and crossing traces, and flags design errors. Projects are saved in the browser, work offline and can be exported as JSON. Since it's a PWA, you can install it on a computer or a phone.

The simulation and the interpreter have Vitest tests, saving and opening projects is tested with Playwright, and every push publishes a new version to GitHub Pages.
