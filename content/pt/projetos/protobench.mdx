O ProtoBench é basicamente um Tinkercad que fiz para entender e projetar circuitos melhor, tanto para estudo quanto para integração direta com IA. Você monta o circuito em protoboard, placa perfurada, veroboard ou Arduino/ESP32, liga as peças e vê como ele se comporta antes de soldar qualquer coisa. Dá para usar direto no navegador: [jovidasilva.github.io/ProtoBench](https://jovidasilva.github.io/ProtoBench/).

## Como funciona

A simulação resolve o circuito de verdade. Ele vira um sistema de equações pela análise nodal modificada, resolvido pelo método de Newton-Raphson, e é isso que permite simular peças como diodos, transistores, reguladores, relés e PWM. Também tem um interpretador de código Arduino, que lê, verifica e executa o sketch.

O app também revisa a montagem: encontra as ligações elétricas, os pontos de solda e as trilhas que se cruzam, e aponta erros de projeto. Os projetos ficam salvos no navegador, funcionam offline e podem ser exportados em JSON. Como é um PWA, dá para instalar no computador ou no celular.

A simulação e o interpretador têm testes com Vitest, o fluxo de salvar e abrir projetos é testado com Playwright, e cada push publica uma versão nova no GitHub Pages.
